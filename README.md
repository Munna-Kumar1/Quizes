🧠 Java Console Quiz Application

A simple console-based quiz application built using Java. This project allows users to attempt multiple-choice questions, calculates the score, and displays the final result at the end.

🚀 Features
❓ Multiple-choice questions (MCQs)
⌨️ User input via console
📊 Automatic score calculation
🏁 Final result display
🔁 Easy to extend with more questions
💡 Beginner-friendly Java project
🛠️ Technologies Used
Java
Console (Terminal/Command Line)
Scanner class for input handling
